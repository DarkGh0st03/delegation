# R352.1 — Actual failed A2A Test, original authenticated Runner FAIL, one bounded ADK D1 proposal

The R352.0 owner preflight had an unreachable successful-failure path: the protected ADK Test Agent correctly marks failed Runner tests as **A2A TASK_STATE_FAILED**, so no completed A2A report is available to the original host. The preflight previously required a report from a completed A2A Test Task. The original host's generic dispatch catch also retired the root, preventing in-session D1 even when the Runner had already published authenticated FAIL evidence.

R352.1 adds an **explicit opt-in failure lane only for a signed Test Task**. The original native Runner preflight stores a private runtime Task → immutable intent index after the actual Gateway reservation; later it independently proves the original one-shot POST through the durable Runner attempt journal. A separate owner-injected MAC-protected failure observer must share that EXACT journal, not a structural imitation or the possibly writer-privileged Gitea client. When the real protected A2A SDK terminates unsuccessfully, the host consults only this original proof through R339: signed root, exact Test/Child/flight IDs, live original Gitea HEAD, authenticated Runner FAIL receipt, actionable failed phase, and permission containment. Only then can the root remain active in a **failure-preflight-only** state. No A2A/model-provided text or status is accepted as failure evidence. Any missing/tampered/ambiguous proof retires the root.

After the authenticated failure gate, the original owner permits ONE scripted ADK Task candidate proposal. It receives only the authenticated failed phase/digest, original permission ceiling and independently Gateway-attested completed Task IDs. The proposed role and exact permission set MUST match the independently preflighted D1 candidate, and must pass the existing strict ADK permission/agent validation. It **does not** create a Task, issue a Child, mark the failed Test as completed or permit provider/retest work.

The free integration regression uses real ADK and protected A2A SDK role servers, original durable Runner attempt journal, branded RunnerClient, real authenticated FAIL evidence publisher, independently initialized observer, original R349 host and R339 preflight. Its HTTP Runner and Gitea sources are in-memory fixtures; native Rust/EVM/OPA and actual Docker FAIL are NOT claimed. It also proves that the ordinary next-Task decision gate stays closed and a D1 model turn cannot be repeated.
