# R339 — Original Engineer-root-bound native D1 planning preflight

R338's negative native Docker integration is a separate free gate.
R339 introduces a read-only owner-side preflight for future D1 Tasks.

Only the original live signed Engineer Coordinator, its genuine
native-issued Test Child, the immutable original Runner intent, and
R336/R337's independently verified failed-Runner observer may supply
the failure source. The callback runs under the original approved
authority, and its root/Child are rechecked after asynchronous
failure observation.

Each proposed recovery Task must have exactly one native side effect
and canonical resources under the same Engineer permission ceiling.
The preflight returns **no** permission grant, Child credential,
registered Task or Gateway completion. Model/A2A Test FAIL strings
and a changed Gitea commit cannot substitute for owner evidence.

This does not yet admit or execute D1; the Gateway's historical
prebind check cannot be reused after a consumed Runner flight.
The actual verified failed-flight handoff and native D1 E2E remain
separate milestones. No paid model use and no main mutation.
