# Temporary reference material

Everything under this directory is intentionally outside the active `src/` tree.

These files are retained because parts of them may become useful later during the thesis, but they are **not required for the baseline implementation** currently being studied and adapted.

## What is stored here

- original benchmark code and benchmark-oriented `main.rs`;
- CSV writer used by the original benchmark suite;
- PJV implementation used as an alternative/comparison in the original repository;
- Delegate SD-JWT implementation and related variants;
- "efficient" variants of the authors' implementation;
- helper code used only by those variants or comparisons.

Do not treat these files as part of the current implementation unless they are deliberately brought back into the active source tree.

The original repository state before this cleanup is also preserved in the branch `original-backup-before-thesis-cleanup`.
